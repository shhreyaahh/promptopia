# ✨ Promptopia – AI Prompt Sharing Platform

Promptopia is a full-stack web app where users can create, discover, and share AI prompts with the community.

💻 **GitHub Repo:** https://github.com/shhreyaahh/promptopia  
🚀 **Live Demo:** https://promptopia-one-self.vercel.app/

---

## 🌟 Features

- 🔐 Google Authentication
- 📝 Create, Edit, Delete Prompts
- 🔎 Search Prompts by Tag or Keyword
- 👤 View User Profiles
- 📱 Responsive UI

---

## 🛠 Tech Stack

**Frontend**
- Next.js / React
- Tailwind CSS

**Backend**
- NextAuth Authentication
- MongoDB Atlas
- Mongoose

**Other Tools**
- Google OAuth
- Vercel Deployment
